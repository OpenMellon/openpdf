# Getting help

- **How do I…?** Start with the [README](README.md) and the
  [API reference on pkg.go.dev](https://pkg.go.dev/github.com/OpenMellon/openpdf), where the testable examples sit
  beside the functions they show.
- **Questions and ideas**: ask in [Discussions](https://github.com/OpenMellon/openpdf/discussions).
- **Bugs**: open a [bug report](https://github.com/OpenMellon/openpdf/issues/new?template=bug_report.yml) with a
  minimal Go program and the PDF that triggers it.
- **Feature requests**: open a
  [feature request](https://github.com/OpenMellon/openpdf/issues/new?template=feature_request.yml).
- **Security vulnerabilities**: report them privately; see [SECURITY.md](SECURITY.md).
